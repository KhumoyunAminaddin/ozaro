# Запуск O'ZARO — около 20 минут

Сайт уже работает: https://khumoyunaminaddin.github.io/ozaro/ — контакты, зеркала и пакеты из презентации уже на нём. Осталось подключить приём заявок в Telegram — это нельзя сделать без вашего телефона и аккаунтов.

## Шаг 1. Telegram-бот (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot` → имя `O'ZARO заявки` → username, например `ozaro_orders_bot`.
2. Скопируйте **токен** (строка вида `123456:ABC...`). Никому его не показывайте и не вставляйте в код сайта.
3. Откройте своего бота и нажмите **Start**. Если заявки должен получать ещё кто-то, например помощник, он тоже нажимает Start.

## Шаг 2. Приём заявок + CRM-таблица (10 минут)

1. Создайте Google Таблицу «O'ZARO CRM».
2. **Расширения → Apps Script**, удалите всё содержимое и вставьте файл `backend/Code.gs`. Сохраните.
3. **⚙ Настройки проекта → Свойства скрипта → Добавить:** `BOT_TOKEN` = токен из шага 1.
   - `CHAT_IDS` можно не заполнять: `setup()` возьмёт его из вашего сообщения боту. Чтобы добавить помощника, напишите боту `/id` с его телефона и допишите этот id через запятую.
4. В редакторе выберите функцию **setup** → **Выполнить** → разрешите доступы. В Telegram придёт сообщение «✅ бот подключён».
5. **Развернуть → Новое развёртывание → Тип: Веб-приложение**. Параметры: «Выполнять как: **я**», «У кого есть доступ: **все**» → Развернуть → скопируйте **URL** (`https://script.google.com/macros/s/.../exec`).

## Шаг 3. Подключить сайт (1 минута)

Пришлите URL из шага 2.5 — я впишу его в `site/config.js` (поле `leadEndpoint`), и сайт обновится сам. Или впишите сами прямо на GitHub: файл `site/config.js` → ✏️ → Commit.

Пока `leadEndpoint` пустой, форма тоже работает: текст заявки копируется, и открывается Instagram Direct @ozaro.uz.

Всё остальное — тексты на русском и узбекском, цены, зеркала — меняется в `site/config.js` и `site/i18n.js`; фото — в `site/img/`.

## Шаг 4. Домен ozaro.uz (по желанию)

Сейчас домен `ozaro.uz` не отвечает. Зарегистрируйте его у любого регистратора .uz (около 100 000 сум в год) и создайте у регистратора запись `CNAME www → khumoyunaminaddin.github.io`. Затем GitHub → Settings → Pages → Custom domain: `www.ozaro.uz`.

## Как это работает каждый день

```
Клиент → сайт (RU/UZ) → форма → Apps Script ─┬→ строка в Google Таблице (CRM)
                                             └→ Telegram на ваш телефон:
                                                 🪞 Заявка №12, 📅 дата, ✍️ надпись, 📞 звонок
                                                 ⚠️ «на эту дату уже 2 заказа»
                                                 [💳 Предоплата] [🚚 Доставлено]
                                                 [📦 Забрали]    [❌ Отказ]
```

- Нажатие кнопки меняет статус в таблице (обновление — до 1 минуты).
- **9:00** — план на сегодня и завтра: какие зеркала везти, куда, какая надпись, получена ли предоплата.
- **20:00** — итог дня.
- Команды: `/plan` — события на 7 дней, `/new` — заявки без ответа, `/today`, `/week` — сводки.
- Защита от спама: скрытое поле-ловушка и не больше 3 заявок с одного номера за 10 минут.
