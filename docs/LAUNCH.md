# Запуск OZARO — 4 шага, около 30 минут

Эти шаги нельзя сделать без вашего телефона и ваших аккаунтов. После них всё работает само: вы получаете заявки в Telegram и занимаетесь производством и доставкой.

## Шаг 1. Telegram-бот (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot` → имя `OZARO заявки` → username, например `ozaro_orders_bot`.
2. Скопируйте **токен** (строка вида `123456:ABC...`). Никому его не показывайте и не вставляйте в код сайта.
3. Откройте своего бота и нажмите **Start**. Если заявки должен получать ещё кто-то, например помощник, он тоже нажимает Start.

## Шаг 2. Приём заявок + CRM-таблица (10 минут)

1. Создайте Google Таблицу «OZARO CRM».
2. **Расширения → Apps Script**, удалите всё содержимое и вставьте файл `backend/Code.gs`. Сохраните.
3. **⚙ Настройки проекта → Свойства скрипта → Добавить:** `BOT_TOKEN` = токен из шага 1.
   - `CHAT_IDS` можно не заполнять: `setup()` возьмёт его из вашего сообщения боту. Чтобы добавить помощника, напишите боту `/id` с его телефона и допишите этот id через запятую.
4. В редакторе выберите функцию **setup** → **Выполнить** → разрешите доступы. В Telegram придёт сообщение «✅ бот подключён».
5. **Развернуть → Новое развёртывание → Тип: Веб-приложение**. Параметры: «Выполнять как: **я**», «У кого есть доступ: **все**» → Развернуть → скопируйте **URL** (`https://script.google.com/macros/s/.../exec`).

## Шаг 3. Настройка сайта (5 минут)

Откройте `site/config.js` и заполните:
- `leadEndpoint` — URL из шага 2.5;
- `phone`, `telegram`, `instagram` — ваши контакты;
- `products` — ваши товары, цены и фото (фото положите в `site/img/`, в поле `img` укажите `"img/имя.jpg"`).

Пока `leadEndpoint` пустой, сайт всё равно работает: при отправке формы открывается Telegram с готовым текстом заявки.

## Шаг 4. Публикация (5 минут)

1. Влейте ветку в `main`.
2. GitHub → репозиторий → **Settings → Pages → Source: GitHub Actions**.
3. После каждого изменения `site/` в `main` сайт обновляется автоматически: `https://khumoyunaminaddin.github.io/ozaro/`.
4. *(Необязательно)* Домен `ozaro.uz` (около 100 000 сум в год у регистраторов .uz) → Settings → Pages → Custom domain, у регистратора — запись CNAME на `khumoyunaminaddin.github.io`.

> GitHub Pages для приватного репозитория доступен только на платном тарифе. Если репозиторий приватный — сделайте его публичным (секретов в коде нет, токен хранится в Google) или опубликуйте папку `site/` бесплатно на Netlify или Cloudflare Pages простым перетаскиванием.

## Как это работает каждый день

```
Клиент → сайт → форма → Apps Script ─┬→ строка в Google Таблице (CRM)
                                     └→ Telegram на ваш телефон:
                                         🆕 Заявка №12, 📞 кнопка звонка
                                         [✅ Принят] [🛠 В производстве]
                                         [🚚 Доставлен] [❌ Отказ]
```

- Нажали кнопку → статус в таблице меняется сам (обновление занимает до 1 минуты).
- `/today`, `/week` — сводка; `/new` — заявки без ответа.
- 20:00 — итог дня, 9:00 — напоминание о необработанных заявках.
- Защита от спама: скрытое поле-ловушка и не больше 3 заявок с одного номера за 10 минут.

## Реклама (автопилот)

Ссылка для рекламы с меткой — тогда в заявке будет видно, откуда пришёл клиент:
`https://<ваш-сайт>/?utm_source=instagram&utm_campaign=start`

Бюджет и настройки — в `docs/BUSINESS_PLAN.md`, раздел 7. Чтобы проверить экономику со своими цифрами, откройте `<ваш-сайт>/calc.html`.
